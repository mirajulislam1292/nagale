# Components

- Logo: original PDF vector, mark/full and onLight/onDark variants.
- PageHeading: page label, h1, supporting copy and optional action.
- Badge: neutral, green or amber, text and check icon where applicable.
- ProviderCard: public profile, skills, clearly labelled demo metrics and profile link.
- AsyncButton: pending lock, error reporting, awaits service operation.
- Empty: empty-list and missing-resource message with recovery action.
- SectionLink: consistent inline navigation with arrow.
- Layout: desktop header, workspace sidebar/mobile horizontal navigation, footer, locale/Lite controls and status notice.

Forms use native controls and visible labels. Order approval uses an inline confirmation rather than a modal. Demo role choice is intentionally accessible without authentication. Dedicated modal/sheet primitives, full styleguide and per-field error summaries are not yet included.
